# 📸 Directorio de Imágenes y Multimedia

Colocá tus fotos en esta carpeta con los siguientes nombres recomendados para que se carguen automáticamente en tu portafolio web y en tu README de GitHub:

## 1. Foto Personal / Perfil
- **`profile.jpg`** o **`profile.png`**: Tu foto profesional (preferentemente fondo neutro o en laboratorio/taller).

## 2. Fotos y Capturas de Proyectos
- **`the-goat.jpg`** / **`the-goat.png`**: Captura de la landing page o del POS de THE GOAT.
- **`agv-storage.jpg`** / **`agv-storage.png`**: Foto de la maqueta física del AS/RS o captura de la GUI en PyQt6.
- **`compukit.jpg`** / **`compukit.png`**: Captura de la PWA de Compukit Taller en móvil/escritorio.
- **`knee-rehab.jpg`** / **`knee-rehab.png`**: Foto del prototipo mecánico o simulación en Simscape.
- **`lora-kipu.jpg`** / **`lora-kipu.png`**: Foto del nodo sensor ESP32 / LoRaWAN en campo o dashboard.
- **`scada-twin.jpg`** / **`scada-twin.png`**: Captura de Factory I/O o dashboard en Ignition.
- **`cidfae-oven.jpg`** / **`cidfae-oven.png`**: Foto del horno de curado o de la pantalla HMI Kinco.
